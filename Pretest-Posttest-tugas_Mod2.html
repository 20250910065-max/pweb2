A. Pre-Test

1. Apa tujuan menggunakan version control dalam pengembangan perangkat lunak?

Untuk mencatat dan mengelola setiap perubahan pada kode, sehingga riwayat perubahan tersimpan dan bisa dikembalikan ke versi sebelumnya kalau terjadi kesalahan. Version control juga memudahkan kerja tim, karena beberapa orang bisa mengerjakan proyek yang sama secara bersamaan tanpa saling menimpa pekerjaan, lalu hasilnya digabungkan.

2. Jelaskan perbedaan antara git add dan git commit!

  • git add memindahkan perubahan pada file ke staging area, yaitu tempat persiapan sebelum perubahan disimpan. Contoh: git add nama_file.
  • git commit menyimpan perubahan yang sudah ada di staging area ke riwayat repository sebagai satu versi, lengkap dengan pesan penjelasan. Contoh: git commit -m "pesan commit".

Jadi git add untuk memilih perubahan yang akan disimpan, sedangkan git commit untuk benar-benar menyimpannya.

3. Bagaimana cara membuat branch baru di Git?

  1. Gunakan perintah: git branch nama_branch
  2. Lalu pindah ke branch tersebut dengan: git checkout nama_branch
  3. Atau bisa sekaligus membuat dan pindah dengan satu perintah: git checkout -b nama_branch

(Di Git versi baru, bisa juga memakai git switch -c nama_branch.)

B. Post-Test

1. Apa fungsi dari git merge dalam workflow Git?

Git merge dipakai untuk menggabungkan hasil kerja dari satu branch ke branch lain. Contohnya, setelah fitur selesai dikerjakan di branch fitur, hasilnya digabung ke branch main supaya isi file dan riwayat commit dari dua branch itu jadi satu.

2. Jelaskan cara mengatasi konflik saat melakukan merge!

Konflik muncul kalau dua branch sama-sama mengubah baris yang sama di file yang sama, jadi Git bingung mau pakai yang mana. Cara mengatasinya:

  1. Cek file mana yang konflik dengan git status.
  2. Buka file itu, nanti ada tanda <<<<<<<,=======, dan >>>>>>> di bagian yang konflik.
  3. Tentukan isi mana yang mau dipakai (salah satu atau digabung), lalu hapus ketiga tanda tersebut.
  4. Simpan file, kemudian ketik git add nama_file
  5. Terakhir git commit untuk menyelesaikan proses merge.

3. Tulis langkah-langkah untuk menambahkan file baru ke repository Git dan melakukan commit.

  1. Masukkan file baru ke folder proyek.
  2. Ketik git status untuk melihat apakah file sudah terdeteksi (statusnya untracked).
  3. Ketik git add nama_file supaya file masuk ke staging area.
  4. Ketik git commit -m "pesan commit" untuk menyimpan perubahan.
  5. Kalau mau dikirim ke GitHub, lanjutkan dengan git push.

2. Workflow Git dengan branch fitur baru dan integrasi ke branch utama

Alur: main (stabil) → buat branch fitur → commit di branch fitur → merge ke main → push → hapus branch fitur.

git checkout -b fitur-readme
echo "# Profil Keluarga" > README.md
git add README.md
git commit -m "Add README"
git checkout main
git merge fitur-readme
git push origin main
git branch -d fitur-readme
git log --oneline --graph
